# IoT-Based-Smart-Home-Automation-System
Developed an IoT-based Smart Home Automation System using Arduino Uno, ESP8266, Blynk IoT, and multiple sensors for remote appliance control, environmental monitoring, and safety alerts.

## 🎯 Project Objectives

✔ Monitor home environmental conditions in real-time  
✔ Detect gas and smoke for home safety  
✔ Detect fire/flame hazards  
✔ Detect rain and environmental changes  
✔ Automatically control lights based on light intensity  
✔ Control home appliances using relay modules  
✔ Detect human movement using PIR sensors  
✔ Monitor the system remotely using Blynk IoT  
✔ Provide real-time sensor data through a mobile dashboard  
✔ Improve home safety, convenience, and automation  

---

## 📱 Blynk IoT Integration

The **Blynk IoT platform** is used for remote monitoring and control.

Through the Blynk mobile application, users can:

- 🌡️ Monitor sensor readings
- 🔥 Monitor fire/flame detection
- 💨 Monitor gas and smoke levels
- 🌧️ Monitor rain detection
- 💡 Monitor and control lighting
- ⚡ Control connected appliances
- 🚨 Monitor safety alerts
- 📊 View sensor data in real-time

---

## ⚙️ Main Features

### 🌡️ Environmental Monitoring

The system monitors environmental conditions using different sensors and displays the collected data through the Blynk dashboard.

### 🔥 Fire & Gas Safety

Gas, smoke, and flame sensors are used to detect potentially dangerous conditions.

When an abnormal condition is detected, the system can activate an alert using the buzzer and provide information through the monitoring system.

### 💡 Smart Lighting

An LDR/light sensor is used to detect light intensity.

The system can automatically control lights depending on the surrounding light conditions.

### 🚶 Motion Detection

PIR sensors are used to detect human movement.

Motion detection can be used for security monitoring and automation.

### 🌧️ Rain Detection

A rain sensor is used to detect rainfall and provide real-time information to the user.
